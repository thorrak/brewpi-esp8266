Glycol Mode

Standalone control page for enabling or disabling glycol mode without changing the bundled web application.

Enable glycol control

When enabled, the controller switches to the glycol-specific cooling logic and no longer requires the chamber sensor for cooling control.

Unknown
Changing this flag forces the controller to OFF. After saving, verify the control mode and setpoint before resuming operation.
This page reads from /api/extended/ and updates the setting with a PUT /api/extended/ request while keeping the other required extended settings unchanged.
